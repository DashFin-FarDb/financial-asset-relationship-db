## Claim being checked

Check that a deterministic graph larger than the existing upper-representative fixture can be built, persisted to an
isolated local database, loaded with exact counts, and accompanied by successful repeated coordination-lock refreshes.
This run does not establish PostgreSQL, hosted, or production capacity.

## Environment and target

- **Environment:** Windows 10, Python 3.12.10, 8 logical CPUs.
- **Target:** Temporary local SQLite files, removed after the run.
- **Data:** Synthetic, generated by `tests.helpers.graph_scale_factory.build_scale_graph` with prefix `SCALE10K`.
- **Size:** 10,000 assets and 50,000 directed relationships (10x the repository's 1,000 / 5,000 upper-representative fixture).
- **Budget:** One sequential local run; 25 lock-refresh attempts; stop on refresh failure or persisted-count mismatch.
  Timings are advisory regression observations only, with no SLO or release threshold.
